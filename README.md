# RPS
Rock paper scissors game for arduino boards
This is my Blinking project for stasis event that is coming up. Rock Paper Scissors Arduino Game This project is a simple rock paper scissors game made with an Arduino, 3 LEDs, and 3 push buttons. The player picks rock, paper, or scissors using buttons and the Arduino randomly picks a move and shows it with LEDs. How it works You press one of the buttons rock paper or scissors. The Arduino then randomly chooses a move for the computer and lights up the matching LEDs red=rock, yellow=paper, red=scissors. The LED stays on for a second so you can see the result, then it resets for the next round. Wiring setup LEDs go to pins 2, 3, 4 (each with a resistor to GND). Buttons go to pins 5, 6, 7. The buttons use INPUT_PULLUP so you don’t need extra resistors for them.I Could add score tracking, buzzer sounds, LCD screen for results. other than that I am really proud of this project.
